# بوت الجمارك المصرية — @ElheibalandCustomsBot

بوت تليجرام خاص بيك: بيحسب الجمارك والضرائب على أي بند في التعريفة المصرية، بيدوّر على البنود بالاسم (عربي/إنجليزي)، بيعرض متطلبات التصدير، وبيطلع تصنيف GS1 (GPC Brick).

---

## 1) التثبيت على ويندوز (مرة واحدة — 5 دقايق)

1. **فك الضغط**: كليك يمين على `customs-bot.zip` → **Extract All** → حط الفولدر في مكان ثابت (مثلاً `Documents`).
2. **شغّل المثبّت**: دبل كليك على `install_windows.bat`.
   - لو ويندوز سأل "Do you want to run this file?" دوس **Run** (ولو ظهرت "Windows protected your PC": **More info → Run anyway**).
   - لو Python مش موجود هيتسطب لوحده (محتاج نت).
3. **التوكن**: هيفتحلك شباك "تثبيت بوت الجمارك":
   - افتح تليجرام → محادثة **BotFather** → دوس **مرة واحدة** على التوكن (السطر البرتقالي اللي شكله `123456789:AA...`) فيتنسخ.
   - ارجع للشباك ودوس **«📋 الصق التوكن»** وبعدين **«تأكيد وتشغيل»**.
4. **افتح البوت** في تليجرام وابعت `/start` — **أول واحد يبعت /start بيبقى المالك**، وبعدها البوت مقفول على حسابك بس.

بعد كده البوت **بيشتغل لوحده في الخلفية كل ما الكمبيوتر يفتح**، ومحتاج الكمبيوتر يكون شغال ومتصل بالنت علشان يرد.

| ملف | وظيفته |
|---|---|
| `install_windows.bat` | التثبيت (ولو شغلته تاني بيعيد تشغيل البوت أو يغيّر التوكن) |
| `start_bot.bat` | تشغيل البوت يدوياً |
| `stop_bot.bat` | إيقاف البوت |
| `uninstall_windows.bat` | إيقاف + إلغاء التشغيل التلقائي |
| `data\bot.log` | سجل التشغيل لو حصلت مشكلة |

> 🔒 التوكن متخزن في ملف `.env` جوه الفولدر — متبعتهوش لحد. لو اتسرّب: BotFather → `/revoke` وبعدين شغّل المثبّت تاني.

## 3) أوامر المالك

| الأمر | الوظيفة |
|---|---|
| `/allow 123456789` | تسمح لحد تاني (شريك/موظف) يستخدم البوت — `/deny` للإلغاء، `/allow` لعرض المسموح لهم |
| `/whoami` | رقمك على تليجرام |
| `/stats` | الاستخدام وحالة البيانات |
| `/setfx USD 52` | سعر صرف ثابت بدل السعر الرسمي (`/setfx USD 0` للرجوع للرسمي) |
| `/devfee 870323 3` | رسم تنمية 3% على البنود اللي بتبدأ بـ 870323 (`0` للإلغاء) |
| `/update` | تحديث التعريفة كلها من موقع الجمارك دلوقتي (40–60 دقيقة في الخلفية) |
| `/version` | نسخة البوت وآخر فحص للتحديث التلقائي |
| `/upgrade` | تحديث كود البوت دلوقتي بدل ما يستنى الفحص الجاي |
| `/restart` | إعادة تشغيل البوت |
| إرسال ملف | `reference.db` أو ملف GPC (`.json`/`.xml`) — ولو أكبر من 20MB ابعته ZIP |

لو عايز تفتح البوت لأي حد: حط `PRIVATE_MODE=false` في ملف `.env` وأعد التشغيل.

## 4) طريقة الحساب

```
القيمة الجمركية (CIF) بالجنيه = V
ضريبة الوارد        = V × فئة البند            (+ جنيه/وحدة لو الفئة نوعية)
رسم التنمية         = (V + الوارد) × النسبة     (لو متعرّف للبند — مش منشور على موقع الجمارك)
ضريبة الجدول        = (V + الوارد) × النسبة     (حسب ملاحظة الموقع: "من القيمة + ر.ض.جمركية")
رسوم الغرف/تأمين صحي = V × النسبة
ض. القيمة المضافة    = (V + الوارد + التنمية + الجدول + الرسوم) × النسبة   (نص قانون ق.م)
أرباح تجارية (أ.ت.ص) = V × 1%                   (دفعة تحت حساب الضريبة للاستيراد بغرض الاتجار/التصنيع)
```
مطابق لمثال Captain Emad: `846595 1522500` → ق.م 213,150 + أرباح 15,225 = **228,375 ج**، والإجمالي **1,750,875 ج**.
الافتراضات قابلة للتعديل في `config.json`.

**حدود لازم تاخد بالك منها**
- النتيجة **تقديرية**؛ النهائي حسب البيان الجمركي والقيمة اللي تقبلها الجمارك وسعر يوم التسجيل.
- **رسم التنمية** و**رسوم الإغراق/الوقاية** مش منشورين في بيانات موقع الجمارك — عرّف رسم التنمية بـ `/devfee`، وراجع الإغراق للبنود الحساسة (حديد، سيراميك…).
- **الآلات للإنتاج** ممكن ق.م عليها 5% بدل 14% حسب الاستخدام.
- أسعار **الاتفاقيات** محتاجة شهادة منشأ وقواعد منشأ.
- البحث بالاسم بيقترح؛ **التصنيف الصحيح مسؤوليتك**.

## 5) البيانات والتحديث

- كل بند بيتسحب لحظياً من موقع مصلحة الجمارك (عرض **الوارد** للفئات واشتراطات الاستيراد، وعرض **الصادر** لمتطلبات التصدير) — كاش 24 ساعة، ولو الموقع واقع يرجع للنسخة المحلية.
- التعريفة كلها بتتحدث لوحدها كل 7 أيام (`AUTO_UPDATE_DAYS`) ويوصلك تقرير بالبنود اللي اتغيرت فئاتها.
- أسعار الصرف: سعر التحويل الجمركي من موقع الجمارك (والبنك المركزي احتياطي) كل 6 ساعات.
- **كود البوت بيحدّث نفسه:** كل نص ساعة البوت بيسأل GitHub (`maboheiba911-star/customs-bot`، فرع `main`) عن نسخة أحدث.
  لو لقى، بينزّلها ويختبرها على نسخة من البيانات قبل أي تغيير، وبعدين يبدّل الملفات (بنسخة احتياطية في
  `data/updates/backups`) ويشتغل بالجديدة. لو الجديدة مقامتش في دقيقتين بيرجع للقديمة لوحده، وفي الحالتين بيبعتلك رسالة.
  يقدر يغيّر بس: `bot.py` وملفات `customs_bot/` و`tools/` و`requirements.txt` وملفات `.bat` — عمره ما بيلمس `.env` ولا `data/`.
  يتقفل بـ `AUTO_UPDATE=0` في `.env`. أي حد يقدر يكتب على الريبو ده يقدر يغيّر كود البوت، فخلي حساب GitHub محمي بكلمة سر قوية وتحقق بخطوتين.
- GS1 GPC: نزّل أحدث نسخة من [GS1 Egypt](https://gs1eg.org/en/tools/gpc-browser/) وابعتها للبوت (ZIP)، أو `python tools/import_gpc.py <file>`.
- المصادر والتراخيص في `DATA_SOURCES.md`.

## 6) تشغيل على سيرفر بدل الكمبيوتر (اختياري)

فيه `Dockerfile` و `deploy/customs-bot.service` (Ubuntu/systemd). على السيرفر: `pip install -r requirements.txt`، ملف `.env` فيه `TELEGRAM_BOT_TOKEN`، و `python bot.py`.
لو السيرفر بره مصر وموقع الجمارك رافضه، البوت بيكمل بالنسخة المحلية، وتقدر تحدّث من كمبيوترك (`python tools/update_tariff.py`) وتبعت `data/reference.db` للبوت.

## 7) للمطورين

```
bot.py                  التشغيل (lock لنسخة واحدة، لوج في data/bot.log، retry لو النت مش جاهز)
customs_bot/
  official.py  fx.py    موقع الجمارك (وارد/صادر) + أسعار البنك المركزي
  taxparse.py  calc.py  قراءة سطور الضرائب الرسمية + الحاسبة
  refdb.py  arabic.py  glossary.py   البحث (عامية، مرادفات، HS إنجليزي، GS1)
  service.py  handlers.py  formatters.py   منطق البوت، القفل على المالك، الرسائل
  builder.py            بناء/تحديث قاعدة البيانات بأمان
tools/                  setup_wizard.py · update_tariff.py · import_gpc.py
tests/                  اختبارات (منها تشغيل كامل للبوت بتليجرام وهمي، والتحديث التلقائي والرجوع للنسخة القديمة)
```
التحديث التلقائي في `customs_bot/handlers.py` (قسم self update)، و`python bot.py --selftest` هو الاختبار اللي بيتعمل
على أي نسخة جديدة قبل ما تتركب. أي push على `main` بيوصل لجهاز المالك خلال نص ساعة، فمتعملش push لحاجة متجربتش.
`pip install pytest pytest-asyncio && pytest`
